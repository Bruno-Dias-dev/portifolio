## Breakpoints do Boosstrap 
- São ultilizados por classes como: sm, md, lg;
- Cada um representa uma media query; 
- Assim é possível trabalhar com conjunto do Bootstrap e deixar o site responsivo.


## Exercício 

index
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <h1>Seção Layout</h1>
    <button class="btn btn-primary">Clica em mim</button>
</body>
</html>


h1 {
    color:red;
}

button {
    background-color: red;
}

/* Sm */
@media (width < 576px) {
    h1 {
        color: blue;
    }
}


## Containers 
- São entidades que estruturam o layout 
- Deposito de outros elementos 
- Temos tipos diferentes de containers
- Serve para separar o site em áreas 


<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <h1>Seção Layout</h1>
    <button class="btn btn-primary">Clica em mim</button>
    <div class="container">
        <h2>Seção container</h2>
        <p>Exemplo</p>
        <p>Exemplo</p>
        <p>Exemplo</p>
    </div>
</body>
</html>

h1 {
    color:red;
}

button {
    background-color: red;
}

/* Sm */
@media (width < 576px) {
    h1 {
        color: blue;
    }
}

.container h2 {
    color: grey;

}
